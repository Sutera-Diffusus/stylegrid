# 九宫格风格清单（gridkit）

用法：`python gridkit.py --src 照片.jpg --out out/ --order 风格1_配色,风格2_配色,...`

- **配色**：`A / B / C / D / E` 五组（A 暖红奶油、B 冷蓝奶油、C 青绿、D 品红、E 米白+深蓝）
- **画幅**：`--aspect 3:4 | 1:1 | 4:3`（按比例中心裁切，不拉伸）
- **自动推荐**：`--suggest`（按画面特征选八格、按偏好排序）；`--all` 出全部风格
- **手控兜底**：`--mode poly --poly "x1,y1;x2,y2;..."` 或 `--mode mask --mask fg.png`

## 一、照片保真类（保留照片内容与质感）

| 风格 | 名称 | 内容 |
|---|---|---|
| `pixel` | 像素画 | 降采样到逻辑分辨率 → 中位切分色板(14–30 色) + Floyd–Steinberg 抖动 → 最近邻放大 → 主体 1px 墨线描边 |
| `dotmatrix` | 点阵印刷 | 每格按"暗度"画圆点（暗→大点），点的颜色取该格均色，纸色底 |
| `mosaic` | 马赛克 | 小方砖取格均色 + 砖缝 + 每砖轻微色差 |
| `cross` | 十字绣 | 亚麻布底 + 每格绣一个 X（线色=格均色，中位切分色板），像把照片绣成图案 |
| `quilt` | 拼布 | 画面切块 + 虚线缝线 + 每块轻微色调抖动（不旋转，主体完整） |
| `strips` | 拼接条带 | 照片切成竖条、隔条微微错位 + 细缝 —— 拼贴/重排感 |
| `collage` | 照片拼贴 | 整幅照片打底 + 主体附近叠几张硬边裁块（纸边硬边、无软投影） |
| `film` | 胶片接触印相 | 整幅铺作片基 + 分格白线 + 左右齿孔 + 片边黑条 |
| `glitch` | 故障化 | RGB 通道偏移 + 少量横向块错位 + 轻扫描线（车体完整可辨） |
| `pixelsort` | 像素排序故障 | 列内"非主体"区段按亮度排序 → 背景被拉成光带、云层垂成丝，主体不动 |
| `motion` | 拖影 | 多帧平移叠加，运动残影（效果最"化"，慎用） |
| `polar` | 极坐标 | 画面极坐标重映射（旋涡/环形展开） |
| `scanlines` | 扫描色带 | 亮度压成「墨/中间色/纸」三档 + 纸色横线纹理；主体反白保读 |
| `halftone` | 网点 | 圆形网点阵按暗度排布（有真实光源时追加光环装置） |

## 二、图形剪影类（抽象为两色/几何）

| 风格 | 名称 | 内容 |
|---|---|---|
| `flat` | 剪纸平涂 | 天空色平涂 + 主体色块 + 硬投影 |
| `hardedge` | 硬边剪影 | 深浅两色硬边平涂，可叠加主体轮廓线 |
| `papercut` | 剪纸层叠 | 分层剪纸造型 + 层间硬边 |
| `inkmin` | 极简墨线 | 低对比极简双色（安静、弱对比） |
| `lineart` | 轮廓线稿 | 只画主体外轮廓 + 内部细节线（缩到小尺寸也分得清结构） |
| `blocks` | 色块分割 | 画面切成色块网格，每块取平均色（蒙德里安式） |
| `shards` | 碎片棱镜 | 画面切成三角碎片重排 |
| `pattern` | 重复图案 | 主体/画面做成可平铺的重复母题（适合布料、壁纸） |
| `deco` | 放射装饰 | 装饰艺术风格放射线 + 同心环（检测到真实光源时启用） |

## 六、原作痕迹校准（可量化检验）

**指标**：`痕迹分 = 0.65 × |32×32 亮度布局相关系数| + 0.35 × 色彩接近度`（1.0 = 与原作完全一致）

- **强痕迹 ≥0.85**：glitch(0.98)、quilt(0.97)、pixel(0.97)、pixelsort(0.97)、mosaic(0.95)、collage(0.95)、strips(0.94)、cross(0.93)、film(0.93)、splatter(0.90)、opart(0.90)、motion(0.89)、blocks(0.89)、dotmatrix(0.89)、negative(0.86)
- **中痕迹 0.50–0.85**：cyanotype(0.76)、polar(0.71)、cubism(0.69)、duotone(0.67)、destijl(0.63)、scanlines(0.62)、halftone(0.61)、mirror(0.60)、flat(0.57)、hardedge(0.56)、colorfield(0.54)、deco(0.53)、papercut(0.52)
- **弱痕迹 <0.50（"意译"级或刻意单色）**：riso4(0.42)、supremat(0.40)、shards(0.40)、lineart(0.39)、engraving(0.39)、bauhaus(0.39)、kandinsky(0.32)、inkmin(0.31)、pattern(0.29)

本轮修复（原始 → 校准后）：
`opart 0.02→0.90`、`splatter 0.33→0.90`、`blocks 0.22→0.89`、`polar 0.10→0.71`、`destijl 0.06→0.63`、
`supremat 0.10→0.40`、`kandinsky 0.02→0.32`、`bauhaus 0.29→0.39`；
`pattern` 已重做（母题尺寸/颜色由照片驱动），但其"重复"本质使它仍是低分——默认不再进池。

原则：**强/中痕迹风格才进默认推荐与九宫格**；弱痕迹风格（含 `lineart/inkmin/engraving` 这类刻意单色）保留可手动调用。
原始分数表见 `_痕迹分.json`。

## 八、方向一：风格混血（`mixposter.py`）

**引擎**：多风格图层叠加，支持 8 种混合模式 `NRM/MUL/SCR/OVR/LGT/DRK/ADD/DIF` × 三种作用域
`A` 整体 / `S` 仅主体（用掩版）/ `B` 仅背景；权重可调。

**自定义**：`--one "pixel_E*1+risomis_A:MUL@B"` —— 风格_配色 * 权重 : 模式 @ 作用域，`+` 连接。
或直接调配方：`--mix riso_pixel,print_cross,...` 出 3×3 混血格。

## 九、方向二：海报版式（`--poster V|S|H`）

- **V 竖版**（3:4）：画作居中偏上 + 右侧**竖排题签柱**（标题逐字）+ 细线 + 底部说明条（副题／风格名）；
- **S 方版**（1:1）：画作居中 + 下方横排标题 + 右对齐风格名；
- **H 横版**（4:3）：画作居左 + 右侧竖排题签 + 右下角说明；
- 画作可直接用**混血配方**（如 `--style riso_pixel`）。

成品：`D:\omp\photo_edit\海报版式\V / S / H`（同一混血画作三种版式）+ `H2`。
